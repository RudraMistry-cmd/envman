# What is OrbStack? [​](#what-is-orbstack)

[OrbStack](https://orbstack.dev) is a fast, light, and simple way to run containers and Linux machines. It's a supercharged alternative to Docker Desktop and WSL, all in one easy-to-use app.

Keep reading to learn more, or [get started](./quick-start) right away.

## Why OrbStack? [​](#why-orbstack)

- ⚡️ **Lightning Fast.** Starts in 2 seconds, optimized [network](./docker/network) and file system, fast x86 emulation.
- 💨 **Feather Light.** Low CPU and disk usage, [battery-friendly](./benchmarks), works with less memory, native Swift app.
- 🍰 **Effortlessly Simple.** Automatic [domain names](./docker/domains) and [migration](./install#docker-migration), CLI & [container/image/volume file access](./features/native-files), VPN and SSH support.
- ⚙️ **Powerful.** Run [Docker containers](./docker/), [Kubernetes](./kubernetes/), and [Linux distros](./machines/), with [USB passthrough](./features/usb) and [isolated sandboxes](./machines/isolated) for untrusted code. Manage everything from your [menu bar.](./menu-bar)

Check the [website](https://orbstack.dev) for demos, or see what we're up to in the [changelog](./release-notes).

## Getting started [​](#getting-started)

[Download the app](https://orbstack.dev/download) and open it to get started, or follow the [Quick Start](./quick-start) guide.

Switching from Docker Desktop or Colima? It's [effortless](./install#replacing-docker-desktop) — you'll be up and running in no time.
