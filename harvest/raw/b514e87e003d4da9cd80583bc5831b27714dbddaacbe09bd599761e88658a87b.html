What is OrbStack? ​

OrbStack is a fast, light, and simple way to run containers and Linux machines. It's a supercharged alternative to Docker Desktop and WSL, all in one easy-to-use app.

Keep reading to learn more, or get started right away.

Why OrbStack? ​

  • ⚡️ Lightning Fast. Starts in 2 seconds, optimized network and file system, fast x86 emulation.
  • 💨 Feather Light. Low CPU and disk usage, battery-friendly, works with less memory, native Swift app.
  • 🍰 Effortlessly Simple. Automatic domain names and migration, CLI & container/image/volume file access, VPN and SSH support.
  • ⚙️ Powerful. Run Docker containers, Kubernetes, and Linux distros, with USB passthrough and isolated sandboxes for untrusted code. Manage everything from your menu bar.

Check the website for demos, or see what we're up to in the changelog.

Getting started ​

Download the app and open it to get started, or follow the Quick Start guide.

Switching from Docker Desktop or Colima? It's effortless — you'll be up and running in no time.
